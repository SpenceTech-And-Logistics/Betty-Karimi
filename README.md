# Betty Karimi: single-page site (React + Vite)

- All text lives in `src/content.js` (name, bio, ventures, awards, milestones, gallery, contact).
- Photos live in `public/images/`. Replace a file keeping the same name, or change the path in `content.js`.
- Contact details are blank in `content.js` (email, phone, socials, optional Formspree id). Fill them in; empty ones are hidden.
- Run: `npm install` then `npm run dev`. Deploy: `npm run build` and upload `dist/`.
- Not used: `tally3.jpg` (226px) was too small to show well. `download.jpg` (131px) is saved as `public/images/recolte-office.jpg` if you want it.
